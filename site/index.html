Plan only as far as you can see.

Bubble Planner keeps a coding agent on one linear track of task bubbles. Anything not planned yet stays fog, and only the human plans fog. The terminal below runs the real CLI in your browser, on a disk that lives in this tab.

      How this works
      
    
      The page loads the CLI's committed JavaScript unchanged. Only what Node would provide is swapped: the filesystem lives in memory and the output goes to this terminal. A test replays every scene against the real CLI and fails if one byte differs.
